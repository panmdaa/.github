# Panmda

> Building simple foundations for modern software.

Panmda is an open-source software organization focused on designing and
building modern, independent, and composable tools for developers.

We believe software infrastructure should not require unnecessary
complexity. Our goal is to create focused building blocks that are easy
to understand, efficient to use, and capable of working together without
forcing developers into a particular ecosystem.

## What we do

Panmda develops software across different layers of the development
stack, from low-level primitives and libraries to developer tools and
application infrastructure.

We focus on:

- **Libraries** — Small, focused, and reusable building blocks.
- **Developer tools** — Tools that simplify and improve development workflows.
- **Infrastructure** — Practical foundations for building and running software.
- **Web technologies** — Modern tools for building web applications and interfaces.
- **Server technologies** — Simple and efficient foundations for backend systems.
- **Cross-platform software** — Tools designed to work across different environments.

## Our approach

### Simplicity

We prefer clear solutions over unnecessary abstractions.

### Composability

Software should be useful on its own and become more powerful when combined
with other components.

### Independence

Projects should avoid unnecessary coupling and remain useful outside the
Panmda ecosystem.

### Efficiency

Performance, resource usage, bundle size, and startup time are considered
part of the design.

### Interoperability

We build on open standards and existing platforms rather than creating
unnecessary barriers around our software.

### Developer experience

Tools should be pleasant to understand, integrate, maintain, and use.

## Philosophy

Panmda is not intended to be a single framework or a monolithic platform.

Instead, we build independent pieces of software that solve specific
problems well.

## Open source

Panmda is developed openly.

We welcome experimentation, discussion, contributions, and ideas that help
improve the software and the broader developer ecosystem.
